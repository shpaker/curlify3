# Agent rules

## Commits, pull requests and branches

- No mention of AI, neural networks, language models or assistants in commit messages,
  pull request titles and descriptions, or branch names. This covers attribution trailers
  (`Co-Authored-By: ...`), "Generated with ..." footers, and branch prefixes such as
  `claude/`, `ai/` or `copilot/`.
- Name branches after the change itself, e.g. `feat/include-headers` or `fix/cookie-header`.
